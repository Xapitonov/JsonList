# JsonList
Представляем приложение для Android, оформленное в стиле **Material You**, для просмотра JSON-файлов в удобном списковом формате.

[<img src="https://fdroid.gitlab.io/artwork/badge/get-it-on.png"
     alt="Получить в F-Droid"
     height="80">](https://slavce14.github.io/redirect?link=jsonlist-fdroid)
[<img src="https://gitlab.com/IzzyOnDroid/repo/-/raw/master/assets/IzzyOnDroid.png"
     alt="Получить в IzzyOnDroid"
     height="80">](https://slavce14.github.io/redirect?link=jsonlist-izzy)

Или скачайте последнюю версию APK в [разделе Релизы](https://github.com/SlaVcE14/JsonList/releases/latest).

![JsonList](images/jsonlist_main.jpg)

Использует удобную функцию раздельного просмотра, которая позволяет одновременно отображать необработанную строку JSON и представление в виде списка.

<img src="images/jsonlist_splitview.jpg" width="450">

![JsonList разделенное представление в ландшафтном режиме](images/jsonlist_splitview_landscape.jpg)

Наслаждайтесь гибкостью динамической поддержки цветов, адаптирующейся к вашим предпочтениям **Material Design**.
